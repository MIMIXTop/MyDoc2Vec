# Doc2Vec Model Training and Server

Этот проект предназначен для обучения модели Doc2Vec и последующей обработки документов с использованием обученной модели. Проект состоит из двух основных частей:
- Тренировка модели на основе текстов
- Сервер для обработки документов и получения векторных представлений

## Тренировка модели

### Описание
Модель Doc2Vec обучается на текстовых данных из CSV-файла. После обучения модель и связанные с ней данные сохраняются для дальнейшего использования.

### Файлы для тренировки
- [`main.py`](main.py) — основной скрипт для запуска обучения модели и сохранения результатов.
- [`trainModel.py`](trainModel.py) — содержит логику обучения модели.
- [`doc2vec.py`](doc2vec.py) — реализация модели Doc2Vec и вспомогательных классов.
- [`utils.py`](utils.py) — утилитарные функции для обработки текстов и документов.

### Запуск тренировки
1. Подготовьте данные для обучения в формате CSV-файла с колонкой `text`. По умолчанию используется файл `data.csv`.
2. Убедитесь, что все зависимости установлены с помощью `uv`:
   ```bash
   uv sync
   ```
3. Запустите тренировку модели:
   ```bash
   python main.py
   ```

### Что сохраняется после тренировки
После завершения обучения в файл `model_state.pt` сохраняются следующие данные:
- Состояние модели (`model_state_dict`)
- Словарь для сопоставления слов и индексов (`word2idx`)
- Размер словаря (`vocab_size`)
- Количество документов (`num_docs`)
- Размер эмбеддингов (`embedding_dim`)
- Размер окна контекста (`window`)

Также создается файл `word2idx.txt` с сопоставлением слов и их индексов.

## Сервер для обработки документов

### Описание
Сервер предназначен для обработки документов с использованием обученной модели. Он принимает текстовые документы, преобразует их в векторные представления и вычисляет косинусное сходство между ними.

### Запуск сервера
Для запуска сервера используется файл [`workModel.py`](workModel.py). Этот скрипт загружает сохраненную модель и данные для её работы.

1. Убедитесь, что файл `model_state.pt` создан после тренировки модели.
2. Запустите сервер:
   ```bash
   python workModel.py
   ```

### Пример использования
В текущей реализации сервер обрабатывает документы, перечисленные в скрипте [`test.py`](test.py). Он загружает модель, вычисляет векторные представления документов и выводит косинусное сходство между ними.

### Структура текстовых документов
Документы для обработки должны находиться в директории `TEXT/`. Пример структуры:
```
TEXT/testText.txt
TEXT/testText2.txt
TEXT/testText3.txt
TEXT/testText4.txt
```

## Требования
- Python 3.8+
- Установленный `uv` для управления зависимостями
- Зависимости указаны в файле `pyproject.toml` и фиксируются в `uv.lock`.
